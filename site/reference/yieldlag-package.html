YieldLag: seasonal climate responses and regional crop yields

Description

The package supplies a deterministic, base-R modelling engine and a high-level workflow that keeps tuning, later evaluation, final fitting, and artifact export separate. See [crop_model_config()], [read_crop_data()], [compare_crop_models()], and [write_crop_results()] for the main workflow.
