Run the complete directory-based workflow

Description

Run the complete directory-based workflow

Usage

run_crop_workflow(
  data_dir,
  crop,
  harvest_month,
  output_dir = NULL,
  config = crop_model_config(),
  last_yield_year = NULL,
  predict_through = NULL,
  verbose = TRUE,
  overwrite = FALSE
)

Arguments

data_dir, crop, harvest_month

Passed to [read_crop_data()].

output_dir

Optional artifact directory. 'NULL' performs no writes.

config, last_yield_year, predict_through, verbose

Passed to [compare_crop_models()].

overwrite

Passed to [write_crop_results()].

Value

A 'crop_model_comparison' object.
